# JavaScript Practice Projects

This repository contains a collection of beginner to intermediate level JavaScript projects and exercises. The purpose of this codebase is to help learners practice essential JavaScript concepts such as variables, functions, DOM manipulation, loops, and more.

---

## 📁 Folder Structure

### 🔹 Core Topics
- **1-exercise-solutions/**: Solutions to introductory JavaScript exercises.
- **12-advanced-functions.html**: Contains advanced JavaScript function examples.
- **Arrays and loops/**: Practice materials related to loops and array manipulation.
- **DOM/**: Projects and examples involving DOM manipulation.
- **html,css/**: HTML and CSS practice (dated 29th August).
- **objects/**: JavaScript object practice materials.

## 🚀 Getting Started

You can run any `.html` file directly in your browser to test and view the respective project. No additional setup is required.

---

## 💡 Recommendations

- Begin with `05-variables.html`, `06-booleans.html`, and then move on to `07-functions.html` to build a strong base.
- Explore the Rock Paper Scissors and Calculator projects to see real-world application of basic concepts.
- Review files under the `DOM/` and `objects/` folders to deepen your knowledge.
